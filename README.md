# PetCare Hub

This project is a full-stack MERN application for pet adoption and e-commerce.

## Project Structure

- **`frontend/`**: contains the React + Vite frontend application.
- **`backend/`**: contains the Node.js + Express backend application.

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- MongoDB

### Installation

To install dependencies for both frontend and backend:

```bash
npm run install:all
```

### Running the Application

- **Run Frontend**: `npm run dev:frontend`
- **Run Backend**: `npm run dev:backend`

## Directory Details

### Frontend
- Located in `/frontend`
- Built with React, Vite, and Tailwind CSS.
- To run: `cd frontend && npm run dev`

### Backend
- Located in `/backend`
- Built with Express and Mongoose.
- To run: `cd backend && npm run dev` (requires `nodemon`)
